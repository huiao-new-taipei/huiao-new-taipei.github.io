資料範圍為第11屆法律案，2024年2月1日至2026年10月20日，以議案編號去重。角色互斥：主提案39件、共同提案30件、連署571件，合計640件。主提案依名單首位判定，不能據此確定辦公室執筆分工，也不是三讀通過數。

逐案附原始文件或報導連結，區分法院資料、學術機構決議、當事人自述、新聞直接採訪和批評者立場。法院對周玉蔻與蔡玉真的判決，僅用以說明該案當事人的損害和被告責任，不移植為其他節目來賓的有罪認定。
