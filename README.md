# 人物觀測 002／蘇巧慧 — 公開靜態發佈包 v1

預定網址：https://huiao-new-taipei.github.io/

這是一份獨立的公開紀錄整理，非蘇巧慧本人、競選團隊或立法院官方網站，資料提供者不替分類或結論背書。本包只包含可公開的靜態網站、資料、下載檔與共用前端，不含資料庫後端、工作區研究資料、私人聯絡資料、管理員權限或 Git 歷史。

## 發佈狀態

本包已完成本機整理，**尚未確認 GitHub Pages 遠端部署成功**。Chrome 操作目前無法完成，預定網址與跨站連結不能當作已上線的證明。`release-manifest.json` 中 `remoteDeploymentVerified` 為 `false`。

兩站的投稿與社群遊戲清單使用同一服務。人物識別與人物篩選需要 v17 共用 API／資料庫修補及新來源的 CORS 設定；**本包不宣稱這些遠端更新已完成**。前端只有收到真實收件回條才顯示成功，無法連線不會假造收件或遊戲排行。

## 資料範圍與件數

- 僅第 11 屆法律案，期間為 **2024-02-01 至 2026-10-20**，以唯一議案編號去重。
- **主提案 39 件、共同提案 30 件、連署 571 件；合計 640 件**，三種角色互斥。主提案指提案名單首位，不能由列名推定由哪個辦公室執筆，也不是已三讀法律數。
- 主提案與共同提案共 69 件，已與立法院本人提案 API 交叉核對。連署中 570 件出自 LYAPI 本人清單，另依官方全院 API 與原始議案補回 1 件漏列；全部 640 件另作官方 API 對照，7 件查核 PDF 原件。仍不保證上游零遺漏。
- 已排除 2 件日期落在 2026-10-23 的截止日後資料。流程及最新審議狀態屬擷取時現況，可能晚於截止日，**不是 2026-10-20 當日的歷史快照**。
- **39 件主提案已逐案人工分類；其他 601 件為初步規則分類**，沒有同等人工核對深度。委員會、規範對象、修法目的分開呈現，亦保留替代分類；主題不等於意識形態或支持／反對立場。

這是蘇巧慧的獨立資料集，沒有套用沈伯洋的法案件數或語料。`data/bills.json`、`data/analysis.json` 與下載 CSV 保留逐案來源及方法。

## 政策與發言的限制

官網政策採擷取當時兩頁索引的 **14 個政策套案頁**，每頁等權；頁數不是措施數、預算、發言量或投入時間。未提供可確認日期的資料，保留不明狀態，不把抓取日當作發表日。正式提名切點採 2025-11-26 的民進黨原始公告。

猜題與原話檔案目前有 **9 則官方完整發言片段的精選短引文**，9 個事件，提名前 6 則、提名起 3 則。它們不是全部發言或隨機樣本，不可用來推算所有言論的主題頻率。每則保留逐字稿、前後文、影片與證據位置；會議時鐘不等於已逐秒核聽的影片時間，不編造秒數。猜題每輪最多六題，資料較少時如實出較少題目。

同步率是已公開分類下的主題重疊，不是人品評分，亦無法單靠分布判定欺騙、動機或施政成效。

## 共用遊戲與投稿

兩站讀取固定中央遊戲目錄：https://puwa-taipei.github.io/data/game-catalog.json 。目錄連回各遊戲的原站；紅紙鈔遊戲保留在沈伯洋站，蘇站不把其角色複製為蘇巧慧。中央目錄無法取得時，網站會明示使用本機離線快照；社群 API 無法確認時不把未知數當作零。

投稿保留人物識別。公開署名與私人聯絡各需獨立同意，草稿按人物分開手動保存；私人聯絡及同意勾選不存入草稿。私人聯絡於收件 90 天後不再顯示；未發布稿在最後更新滿 90 天後開始分批清理，實體刪除不保證即時。遊戲必須經人工審核、補齊版本與權利說明並明確發布，才進入公開清單。原話核准不會自動改寫既有題庫。

`contribute/config.json` 的 Supabase 網址與 publishable key 是前端所需的公開設定，不是服務端密鑰。管理員權限仍由服務端驗證；蘇站 `/review/` 只轉往中央審稿頁，不處理登入憑證。

## 校驗與使用

`release-manifest.json` 列出每個有效載荷檔案的相對路徑、位元組數與 SHA-256；因無法自我雜湊，manifest 本身不列入自己的檔案表。完整壓縮檔與 manifest 的校驗值另存於工作區發佈收據，不作遠端部署成功的宣稱。

可將本包部署於支援目錄索引的靜態伺服器。GitHub Pages 使用 `.nojekyll`。靜態發佈 ZIP 採固定檔案排序、權限與時間戳以利重現；現有官方證據與知識庫 ZIP 的原始位元組保持不變。
